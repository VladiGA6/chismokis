# Chismokis

Red social anónima. Una palabra compuesta entre **chisme** y **Chokis**.

One-page construida sobre el lenguaje visual de [Brainwave 2 / BW2 Design System](https://ui8.net): Inter, bordes `#ECECEC`, cards redondeadas, sombras suaves y el color de marca `#001789`.

## Arrancar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
